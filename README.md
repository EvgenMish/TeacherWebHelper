# Рассадка класса

Веб-сайт для учителей: рассадка класса по партам.

- загрузка списка учеников из Excel (`.xlsx`) или ввод вручную; правка и удаление учеников прямо на сайте;
- перетаскивание учеников и парт мышью или пальцем (на телефоне — долгое нажатие);
- случайная рассадка (заполняет класс с передних парт);
- поиск по всем ученикам — показывает, кто где сидит;
- выбор тапом/кликом и управление с клавиатуры (стрелки, Enter, Delete);
- печать из браузера и выгрузка в PDF с названием рассадки и датой;
- до 10 именованных рассадок (переключатель в шапке): создание, переименование, копирование, удаление;
- отмена и повтор действий — до 50 шагов (`Ctrl+Z` / `Ctrl+Shift+Z`), история своя у каждой рассадки и сбрасывается при перезагрузке страницы;
- всё автоматически сохраняется в браузере (localStorage) — на сервер ничего не отправляется;
- светлая и тёмная тема.

Всё работает в браузере: сервер ничего не хранит и только отдаёт статические файлы.

## Разработка

Нужен Node.js 20+.

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # сборка в dist/
```

## Публикация на GitHub Pages (бесплатно)

Сайт собирается и выкладывается автоматически через GitHub Actions (`.github/workflows/pages.yml`) при каждом push в ветки `main` или `web`.

Один раз включить в репозитории: **Settings → Pages → Source: GitHub Actions**.

Адрес: https://evgenmish.github.io/TeacherWebHelper/

Если сборка из ветки `web` упадёт на шаге deploy с ошибкой про правила окружения — в **Settings → Environments → github-pages** добавьте ветку `web` в разрешённые (или слейте `web` в `main`).

## Деплой (Docker)

```bash
docker compose up -d --build   # http://localhost:8080
```

Или без compose:

```bash
docker build -t rassadka-klassa .
docker run -d -p 8080:80 --restart unless-stopped rassadka-klassa
```

Образ двухэтапный: Node собирает сайт, nginx его отдаёт (gzip, кэширование, заголовки безопасности — см. `nginx.conf`).

## Формат файлов

**Excel** — первый лист, по одному ученику в строке:

| A       | B    | C         | D   |
| ------- | ---- | --------- | --- |
| Фамилия | Имя  | Отчество  | Пол |
| Иванов  | Иван | Сергеевич | м   |
| Петрова | Анна |           | ж   |

Пол: `м`/`муж` или `ж`/`жен`.

Рассадки в файлы не сохраняются и из файлов не загружаются — они живут только в браузере. Очистка данных сайта в браузере удалит их.
